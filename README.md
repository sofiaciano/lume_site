# Lume — Livraria online

Projeto escolar de e-commerce fictício de livros, desenvolvido em HTML, CSS e JavaScript.

## Como executar
Abra `index.html` no navegador. Não requer instalação nem servidor.

## Funcionalidades (versão inicial)
- Catálogo com pesquisa e filtro por categoria
- Detalhes de livros
- Carrinho com adição, remoção, quantidades e armazenamento local
- Total e frete demonstrativo
- Checkout com validação de campos
- Simulação de PIX, débito e crédito com até 6 parcelas sem juros
- Confirmação fictícia de pedido
- Layout responsivo

**Importante:** nenhuma transação financeira real é realizada. Não insira dados bancários verdadeiros.

## Estrutura
- `index.html`: estrutura das seções
- `css/style.css`: visual e responsividade
- `js/app.js`: dados, interações e cálculos
